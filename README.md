# Nufus_Simulasyonu
 Oyun dinamik bir nüfus değiştirme simülasyonudur. İlk aşamada Java dili Eclipse ortamında oluşturulan yapının Visual Studio  Code ortamında C diline farklı benzetimler yönüyle bir nevi dönüştürülmesidir.
 
 Java da yerleşik olarak bulunan Kapsülleme ve 
Bileşim özelliklerini C dilinde struct ve Fonksiyon göstericileriyle manuel olarak benzetilmiştir.  Şehirlerin ilçelerden, ilçelerin ise mahallelerden oluştuğu bu "sahiplik" durumu, C'de dinamik bellek yönetimi ve işaretçi dizileri (pointer arrays) kullanılarak 
yönetilmiştir. Kalıtım benzetimi ise Yerleşim adında bir taban sınıfından da nesne oluşturarak sağlanmıştır. Örnek olarak Sehir 
sınıfından bir nesne oluşturulur.
